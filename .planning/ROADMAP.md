# Roadmap: Dragao Careca Admin Web

## Overview

The Angular admin client remains a thin, authenticated orchestrator over the sibling Dragao Careca API. The sectioned operator layout supports episode editing, media staging, AI-generated transcript/summary workflows, YouTube trailer publication, and backend-generated artifact downloads.
