<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted user input → modal state | Checkbox and keyboard actions mutate selected artifact state. |
| API snapshot → rendered template | Backend messages, missing selectors, progress, and URL metadata are interpolated into the UI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-08 | Tampering | Checkbox payload and button handlers | medium | mitigate | Bind controls to fixed component option objects and submit only selected canonical selectors; use native controls and component guards. |
| T-05-09 | Information Disclosure | Modal error/filename rendering | medium | mitigate | Use Angular interpolation/attribute binding for response text and filenames; show human-readable metadata without filesystem path construction. |
| T-05-10 | Denial of Service | Repeated keyboard/click submissions | high | mitigate | Disable active confirmation/retry controls and test duplicate prevention while a job is nonterminal. |
| T-05-11 | Elevation of Privilege | Downloads action in managed table | low | mitigate | Keep the action behind the existing routed Manage screen and authenticated ApiService; the template does not bypass auth or call a separate unauthenticated endpoint. |
</threat_model>
