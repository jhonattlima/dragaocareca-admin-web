<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator -> authenticated API | Untrusted episode/job IDs, bodies, and retry/cancel requests cross the HTTP boundary. |
| API -> YouTube provider | Server-only OAuth and resumable provider/session data cross an external boundary. |
| worker -> persisted job row | Long-running asynchronous writes must be constrained by source identity, revision, and lease. |
| API -> browser DTO/logs | Provider and filesystem data must be reduced to an operator-safe allowlist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Elevation/Tampering | YouTube job routes | high | mitigate | requireAuth, positive IDs, UUID job IDs, episode/job binding, strict title/summary schema, rejection of provider/path/credential fields, and sanitized 404s. |
| T-08-02 | Tampering/Denial | repository + worker retry | high | mitigate | source fingerprint, unique active-source createOrReuse, revision/lease CAS, same-row provider reconciliation, bounded retry. |
| T-08-03 | Information disclosure | DTO, OpenAPI, logs | critical | mitigate | explicit DTO allowlist; only validated privateWatchUrl; omit provider IDs/sessions/source paths/raw errors/credentials and test the omission. |
| T-08-04 | Tampering | source replacement | high | mitigate | obsolete prior source and reject late writes using episode/source/revision/lease predicates. |
| T-08-05 | Denial | provider quota/timeout/network | medium | mitigate | normalized categories, bounded exponential retry, retry timestamps, and no unbounded worker loop. |
| T-08-SC | Tampering | npm installs | high | mitigate | No new package install; retain the existing package set and run the sibling build/verifier. |
</threat_model>
