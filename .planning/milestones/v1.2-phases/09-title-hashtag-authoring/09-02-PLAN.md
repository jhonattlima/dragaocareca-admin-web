<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator/browser → Angular editor | User-controlled episode name and hashtag text enters transient form state. |
| Angular → authenticated ApiService | Authenticated title/hashtag/save/lookup payloads cross into the API contract. |
| asynchronous API response → current editor | Polling and lookup responses can arrive after input, reset, or episode changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-04 | Tampering | ManageComponent async merge | high | mitigate | Guard polling and lookup callbacks by editor/version/token and merge suggestions additively rather than replacing authored text. |
| T-09-05 | Denial of service | Angular lookup debounce | medium | mitigate | Cancel timers/subscriptions on input, dismissal, reset, and destroy; issue only the current normalized lookup after the one-second delay. |
| T-09-06 | Information disclosure | ApiService DTOs | medium | mitigate | Type and consume only approximate count, retrieval, cache state, and safe error fields; never call or expose provider credentials/details. |
| T-09-SC | Tampering | npm installs | high | accept | No package installation is planned; existing Angular/RxJS dependencies are reused. |
</threat_model>
