<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> authenticated API | Untrusted episode ID, multipart metadata, bytes, cancellation, and retry requests enter the route. |
| API -> filesystem | Validated upload bytes cross into staging, prepared, final, and rollback paths. |
| API -> SQLite/draft registry | Authenticated owner and finalized filename/state are persisted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Elevation of privilege | draft reservation and trailer upload | high | mitigate | Issue an opaque reservation from authenticated POST /episodes/drafts, bind it to req.user.email and episodeId, require it on upload/create, and reject unreserved IDs. |
| T-07-02 | Tampering | staging -> final promotion | high | mitigate | Validate server-derived paths, use prepared rename, preserve rollback copy, and update the repository only after final bytes are ready. |
| T-07-03 | Denial of service | Multer trailer upload | medium | mitigate | Enforce MP4/MIME/extension/max-byte limits and remove partial files on parser, disconnect, and terminal failure. |
| T-07-04 | Information disclosure | API response/logging | medium | mitigate | Return canonical relative media names and lifecycle state only; never expose absolute storage paths, owner internals, or provider credentials. |
| T-07-SC | Tampering | npm install/build verification | high | mitigate | Use the existing dependency set and run sibling API build plus the isolated verifier; no new package is introduced. |
</threat_model>
