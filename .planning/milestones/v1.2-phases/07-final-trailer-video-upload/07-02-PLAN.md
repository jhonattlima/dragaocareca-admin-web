<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file picker/drag-drop -> Angular state | Browser-controlled File metadata and events enter component state. |
| Angular -> authenticated API | Episode ID and multipart bytes cross the shared HttpClient/interceptor boundary. |
| API response -> editor state | Untrusted response timing and lifecycle data can race with replacement/reset actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05 | Tampering | upload generation state | high | mitigate | Associate every event with episode ID, server-issued draftId, and generation token; ignore stale A callbacks after B/reset/destroy. |
| T-07-06 | Denial of service | browser upload subscription | medium | mitigate | Unsubscribe on cancel, replacement, reset, and teardown while retaining the File for an intentional retry. |
| T-07-07 | Information disclosure | Angular media state | low | mitigate | Store only the selected File and API-relative filename; never expose filesystem paths or provider credentials. |
| T-07-10 | Elevation of privilege | Save/create draft wiring | high | mitigate | Send only the server-issued draftId with the matching episodeId; do not permit client-created IDs or finalize on a staged upload response. |
| T-07-SC | Tampering | npm install/build verification | high | mitigate | Use existing Angular/RxJS/Bootstrap dependencies and run focused/full Karma plus `npm run build`. |
</threat_model>
