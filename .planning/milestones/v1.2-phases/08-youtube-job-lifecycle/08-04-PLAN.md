## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator -> Angular controls | User actions can race with reload, replacement, and cancellation. |
| API snapshot -> component state | Late/stale responses must not mutate a different episode/source. |
| Angular template -> operator | Incorrect labels could imply public publication or hide accepted provider work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-11 | Tampering | Manage polling/state | high | mitigate | Guard every callback by episode, job ID, source generation, and terminal state; clear timers/subscriptions on all lifecycle boundaries. |
| T-08-12 | Information disclosure | templates | medium | mitigate | Render normalized categories/private URL only; never bind raw provider/session/source fields. |
| T-08-13 | Repudiation | cancellation UI | medium | mitigate | Preserve durable cancel_requested snapshot and explicitly distinguish local-cancelled versus provider-video-retained. |
| T-08-14 | Tampering | publication boundary | high | mitigate | No Publish action or public wording in Phase 8 templates/tests; private-ready is the terminal UI state. |
| T-08-SC | Tampering | npm installs | high | mitigate | No package installation; use the existing Angular test/build toolchain. |
</threat_model>
