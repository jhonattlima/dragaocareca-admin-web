## Publication date defaults

| Option | Description | Selected |
|--------|-------------|----------|
| Preserve latest date/time and add seven calendar days | Keeps the latest episode’s local time and timezone representation. | ✓ |
| Normalize to a fixed time | Would discard the latest episode’s time component. | |

**User's choice:** Preserve the date/time and add seven days; use current date/time when there is no previous episode.
**Notes:** The default is episode-only and should represent the next publication date.

## Audio metadata

| Option | Description | Selected |
|--------|-------------|----------|
| Episode audio only | Trailer audio behavior remains unchanged. | ✓ |
| All audio uploads | Would also change trailer-audio behavior. | |

**User's choice:** Episode audio only.
**Notes:** Duration should be shown as hours, minutes, and seconds. Metadata is applied after upload from backend-confirmed values. The assistant may choose the byte unit; decimal MB was selected. Metadata extraction failure must fail the upload because the fields are mandatory.

## Participant defaults

| Option | Description | Selected |

**User's choice:** Store the default participant list in frontend configuration.
**Notes:** Select configured participants only when they exist in the current participant catalog; unknown configured names are ignored.

## Music validation

**Notes:** This is a required save invariant.
