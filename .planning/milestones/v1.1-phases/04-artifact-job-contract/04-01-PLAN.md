<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP/request data -> job persistence | Untrusted episode and selector values are normalized before any job row or path is created. |
| Worker -> media filesystem | Server-resolved catalog paths and opaque job directories are used for reads and writes. |
| SQLite metadata -> download service | Persisted paths are internal metadata and must be validated before any stream is opened. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-04-01-01 | Tampering | selector-to-path resolution | critical | mitigate | Keep selector resolution in the existing catalog/preflight service; repository stores normalized selector arrays, never client paths or filenames. |
| T-04-01-02 | Information Disclosure | job repository/status snapshot | high | mitigate | Use random opaque IDs, episode-scoped lookups, and a public mapper that excludes archive paths, storage roots, cache keys, and raw filesystem errors. |
| T-04-01-03 | Denial of Service | job archive retention | high | mitigate | Use job-specific files, active duplicate coalescing, bounded 45-minute TTL cleanup, and failure cleanup of snapshots and partial ZIPs. |
| T-04-01-04 | Tampering | archive entry names | high | mitigate | Derive entry names only from the fixed catalog and episode ID; never pass request strings to archiver. |
| T-04-01-SC | Tampering | npm/pip/cargo installs | high | accept | No package installation is planned; existing archiver, Zod, SQLite, and Node APIs are reused. |
</threat_model>
