<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Episode row → client availability state | Persisted filenames are an optimistic UI hint, not filesystem authority. |
| Client selection → API job start | Selected canonical selectors cross the authenticated API boundary. |
| API snapshot → component state | Progress, missing selectors, errors, and completion metadata are untrusted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Tampering | Selector submission in `ManageComponent` | high | mitigate | Build payloads from the fixed option selector values only; never derive request data from displayed filenames or paths. |
| T-05-05 | Denial of Service | Start/poll state machine | high | mitigate | Gate active starts, retain per-episode job IDs, use one interval per job, and clear timers at terminal state/destroy. |
| T-05-06 | Information Disclosure | Error and partial-result presentation | medium | mitigate | Display backend error text only as user-facing message data; do not expose filesystem paths or infer them from filename fields. |
| T-05-07 | Spoofing | Focus/invoker lifecycle | low | mitigate | Restore focus to the captured native row button and keep modal actions native and scoped to the selected episode. |
</threat_model>
