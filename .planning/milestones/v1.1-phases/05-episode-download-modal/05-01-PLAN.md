<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Angular client → authenticated API | User-selected selector data crosses into the backend job endpoint. |
| API response → Angular state | Job status, missing selectors, errors, and URL metadata are untrusted response data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | `startEpisodeArtifactJob` payload | high | mitigate | Restrict the public TypeScript selector union and send only canonical selector strings; backend remains authoritative for validation. |
| T-05-02 | Information Disclosure | `EpisodeArtifactJobSnapshot.downloadUrl` | medium | mitigate | Treat the URL as opaque display/state data in Phase 5; do not fetch it or construct filesystem paths in the client. |
| T-05-03 | Spoofing | Artifact job HTTP calls | high | mitigate | Reuse the existing HttpClient and AuthInterceptor path so normal authentication behavior and `authBypass` configuration remain unchanged. |
</threat_model>
