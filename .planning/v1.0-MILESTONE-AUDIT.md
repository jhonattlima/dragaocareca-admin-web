## Integration and flow findings

### Backend state race — fixed

In `dragaocareca-admin-api/src/services/episode-transcription.service.ts`, the draft transcription completion path now awaits `writeDraftStateAsync(...)` before calling `queueDraftEpisodeSummary()`. This closes the previously identified overwrite race. The fix is present in API commit `3629492`.

The API repository typechecks successfully. Its package has no automated test script covering this transition, which remains non-blocking technical debt.

### Frontend unavailable-endpoint handling — fixed

Summary polling errors now set `summaryStatus=error` and preserve the backend/HTTP message for the existing status alert. The episode form remains editable, and a regression test covers an unavailable summary endpoint. Transcription polling errors receive the same visible treatment.

### Documentation drift — fixed

The required docs now document `GET /v1/episodes/:episodeId/episodes-generated-summary` and the transcript-to-summary polling flow.
